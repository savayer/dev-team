# Контракт API

Контракт лежит в `.team/contracts/<фича>.md`. Автор один — тот, кого назначил head-pm в плане. После старта фронта контракт правит только head-pm; остальные пишут изменения в CONTRACT CHANGES.

Разделы по порядку, пустой раздел — «нет»:

1. **Эндпоинты:** метод, путь, кто имеет право вызывать.
2. **Запрос и ответ:** поля, типы, обязательность, ограничения валидации — одни и те же для бэка и фронта.
3. **Ошибки:** HTTP-статус + машинный `code` + когда возникает. Формат тела ошибки один на весь проект — бери существующий.
4. **Списки:** пагинация (курсор или offset), сортировка, фильтры, максимальный размер страницы.
5. **Мутации:** идемпотентна ли повторная отправка; что будет при частичном успехе в пакетных операциях.
6. **Общие типы:** где лежат типы или схема, из которых фронт их берёт (не переписывает руками).
