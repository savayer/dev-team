## Команды

Агенты запускают их перед отчётом. Каждая команда должна работать из корня репозитория.

- Установка: `<npm ci>`
- Тесты: `<npm test>`
- Линтер: `<npm run lint>`
- Типы: `<npm run typecheck>`
- Сборка: `<npm run build>`
- Локальный запуск: `<npm run dev>`
